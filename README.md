## 🎮 게임 조작법 및 규칙 (Rules & Controls)

### 1. 조작 방법
* **라켓 이동**: 키보드 방향키 `←`, `→`를 이용해 하단 라켓을 좌우로 조작합니다.

### 2. 테니스 룰 및 진행 방식
* **득점 방식**: 실제 테니스 점수 규칙인 `0` ➔ `15` ➔ `30` ➔ `40` 점수 체계로 진행됩니다[cite: 2].
* **승리 조건**: `40`점 상태에서 한 점을 더 획득하면 승리하게 됩니다[cite: 2]!
* **난이도 설정**: 플레이어의 실력에 맞추어 `쉬움`, `보통`, `어려움` 중 선택하여 컴퓨터와 대결할 수 있습니다[cite: 2].
